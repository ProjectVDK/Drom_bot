# DromBot

Инструмент автоматизации для управления платными услугами продвижения
объявлений на классифайд-площадке — вход с сохранением сессии, поиск
нужных объявлений, применение продвижений по расписанию, контроль баланса
и остатков пакетов услуг.

Конфигурация (расписание, правила, история операций) хранится в Google
Таблице — таблица является единственным источником правды для того, что и
когда должно происходить. Код не содержит бизнес-данных: ни правил, ни
аккаунтов, ни расписаний.

## Стек

- Python 3
- [Playwright](https://playwright.dev/) — браузерная автоматизация
- [gspread](https://github.com/burnash/gspread) + Google Service Account —
  чтение/запись Google Таблицы
- GitHub Actions — плановый запуск в облаке

## Архитектура (кратко)

```
Google Таблица (правила, журнал)
        ↕
   run_bot.py  ──►  Playwright (headless) ──► сайт
        ↕
  сохранённые сессии (не в репозитории)
```

Скрипт запускается по расписанию, проверяет, какие действия должны
сработать сейчас, выполняет их с использованием заранее сохранённой сессии
входа, и записывает результат обратно в таблицу.

## Приватность и данные

Все чувствительные данные (учётные данные Google Service Account, сессии
входа в аккаунты) хранятся вне репозитория — как зашифрованные секреты
среды выполнения. Ни правила продвижения, ни структура аккаунтов, ни
финансовые параметры в коде не фигурируют.

Подробная документация по администрированию и эксплуатации — внутренняя,
не публикуется.
