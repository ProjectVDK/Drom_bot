# DromBot — справочник команд

## Настройка нового ЛК

Создать сохранённую сессию (логин один раз, дальше без пароля):
```
python setup_session.py <Город>
```
Если появится СМС-код или капча — скрипт сам поставит браузер на паузу,
пройди проверку вручную и нажми ▶ Resume в Playwright Inspector.

Проверить, что сохранённая сессия ещё рабочая:
```
python check_session.py <Город>
```

Если у одного ЛК несколько городов (как Хабаровск/Благовещенск) —
после создания сессии для основного города просто скопируй файл:
```
copy sessions\Хабаровск.json sessions\Благовещенск.json
```

## Модели и выпадающий список

Пересобрать список моделей по всем ЛК (у которых есть сессия в sessions/)
и обновить выпадающий список в "Правилах":
```
python collect_models.py
```
Запускать заново после добавления новых сессий или изменения ассортимента.

## Ручное тестирование продвижения

Применить конкретное действие к конкретному объявлению вручную (для теста):
```
python promote_listing.py <Город> "<Модель>" up       # Поднять
python promote_listing.py <Город> "<Модель>" sticky   # Прикрепить
```

## Баланс и пакеты

Посмотреть баланс и остатки пакетов конкретного ЛК в консоли (без записи в Журнал):
```
python dashboard_scraper.py <Город>
```
Для записи в Журнал через таблицу — используй правило с "Баланс"
в столбце "Тип продвижения" (см. ниже).

## Главный бот

Основной запуск (обычно через Планировщик заданий, каждые 5 минут в окне
06:00–10:00 по местному времени / 23:00–03:00 UTC):
```
python run_bot.py
```
Читает "Правила", сверяется с "Журналом", выполняет due-действия,
сканирует баланс/пакеты, пишет результат в "Журнал" (новые записи — сверху).

## Формат листа "Правила"

| Город | Модель | Тип продвижения | Время запуска (UTC) | Дни (UTC) | Группа |
|---|---|---|---|---|---|

- **Тип продвижения**: `Поднять`, `Прикрепить`, или `Баланс` (только сканирует
  и логирует баланс+пакеты для города, без продвижения — Модель/Группа пустые)
- **Время запуска (UTC)**: `ЧЧ:ММ`, 24-часовой формат
- **Дни (UTC)**: через запятую — `Пн,Вт,Ср,Чт,Пт,Сб,Вс`
- **Группа**: непустое значение объединяет строки в пул — из пула в день
  продвигается только 1 модель (та, что дольше всего не продвигалась),
  скоуп пула — Группа + Город вместе (одноимённые группы в разных городах
  независимы друг от друга)

## Диагностика (если что-то не работает)

Посмотреть HTML страницы объявлений (для отладки селекторов):
```
python dump_listings_html.py <Город>
```

Посмотреть HTML главной страницы ЛК (баланс/пакеты):
```
python dump_dashboard_html.py <Город>
```

Проверить обычный вход (без сохранения сессии), полезно для первичной диагностики:
```
python test_login.py <Город>
```

## Файлы, которые нельзя никому пересылать

- `credentials.json` — ключ Service Account для Google Sheets
- `sessions/*.json` — сохранённые сессии (равноценны паролю от аккаунта)
